## 使用说明

1. 将本文档复制为具体文档的检查清单
2. 按文档章节顺序逐项验证
3. 每项填写验证结果：✅ PASS / ❌ FAIL / ⏭ SKIP / ⚠ WARN
4. FAIL 项须填写"文档描述""产品实际""差异分析""修复建议"
5. SKIP 项须填写跳过原因

## 十二、常用验证命令参考

### 参数名提取

```bash
# 提取命令行参数列表
<command> --help 2>&1 | grep -oE '\-\-[a-zA-Z0-9_-]+' | sort -u

# 提取短参数
<command> --help 2>&1 | grep -oE '\-[a-zA-Z]\b' | sort -u

# 提取配置文件项
grep -E '^[a-zA-Z_][a-zA-Z0-9_]*=' /etc/<product>/<config>.conf
```

### 缺省值验证

```bash
# 查看默认配置文件
cat /etc/<product>/<config>.conf

# 不带参数运行查看默认行为
<command> 2>&1 | head -20

# 查看服务默认配置
<command> --show-config 2>&1
<command> config show 2>&1
```

### 版本验证

```bash
# 产品版本
<command> --version 2>&1
<command> -V 2>&1

# OS版本
cat /etc/os-release
uname -r

# 依赖版本
<dependency> --version 2>&1
```

### 输出捕获

```bash
# 捕获输出并保存
<command> 2>&1 | tee /tmp/output_<section>.txt

# 捕获退出码
<command>; echo "EXIT_CODE=$?"

# 捕获JSON输出并格式化
<command> 2>&1 | python3 -m json.tool | tee /tmp/output_<section>.json
```

### 错误场景触发

```bash
# 无效参数触发错误
<command> --invalid-param-xyz 2>&1

# 缺少必需参数触发错误
<command> 2>&1

# 权限不足触发错误
sudo -u nobody <command> 2>&1

# 资源不存在触发错误
<command> --target /nonexistent/path 2>&1
```
