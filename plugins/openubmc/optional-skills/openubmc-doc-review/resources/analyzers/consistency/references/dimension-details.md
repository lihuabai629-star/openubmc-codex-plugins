## 1. 参数名称一致性

**规则**：文档中的命令参数名、配置项名、API参数名必须与产品实际支持的名称完全一致（大小写、连字符/下划线风格、缩写形式）。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 命令行参数名 | 执行 `command --help` 提取参数列表，与文档逐项比对 | required |
| 参数别名 | 验证文档是否使用了有效的参数别名 | suggestion |
| 参数大小写 | 与产品实际大小写严格比对 | required |
| 连字符/下划线风格 | 与产品实际风格比对 | required |
| 配置文件项名 | 读取产品实际配置文件，比对配置项名 | required |
| API 参数名 | 调用API或读取Swagger，比对参数名 | required |
| 环境变量名 | 检查产品代码或文档中实际使用的环境变量名 | required |
| 已废弃参数 | 文档引用了产品已废弃/移除的参数 | required |

**常见违规**：参数名拼写错误、风格不一致（`--log_level` vs `--log-level`）、已废弃参数未更新、参数不存在、缩写不一致。

## 2. 缺省值一致性

**规则**：文档中声明的参数缺省值、配置项默认值必须与产品实际缺省值一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 命令行参数缺省值 | 不带该参数执行命令，观察实际行为 | required |
| 配置文件默认值 | 读取产品默认配置文件（不修改状态） | required |
| 环境变量默认值 | 不设置该环境变量，观察产品行为 | required |
| 运行时默认行为 | 按文档描述的默认场景执行，观察是否与文档一致 | required |
| 数值型默认值 | 验证数值精确度 | required |
| 布尔型默认值 | 验证开关状态 | required |
| 枚举型默认值 | 验证默认选项 | required |

**常见违规**：端口缺省值错误、日志级别错误、开关状态错误、数值精度差异、版本变更未更新。

---

## 3. 回显输出一致性

**规则**：文档中的示例输出（命令回显、日志输出、状态信息）必须与产品实际输出格式和内容一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 输出字段名 | 执行命令比对实际输出的字段名 | required |
| 字段顺序 | 比对实际输出的字段排列顺序 | suggestion |
| 输出格式 | 表格/列表/JSON/YAML格式 | required |
| 数值单位 | 比对数值单位（KB/MB/GB、ms/s/min） | required |
| 状态文本 | 比对状态描述文本 | required |
| 版本号输出 | 执行 `--version` 比对输出格式 | suggestion |
| 对齐与分隔符 | 比对输出中的对齐、分隔符风格 | suggestion |
| 中文/英文输出 | 比对输出语言 | required |

**常见违规**：字段名不一致、单位不一致、状态值不一致、输出格式不一致、语言不一致、行数不一致。

## 4. 操作结果一致性

**规则**：文档描述的操作结果（成功/失败、数据变化、状态变化）必须与产品实际执行结果一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 成功结果 | 执行文档描述的操作，验证结果是否符合文档 | required |
| 失败结果 | 触发文档描述的失败场景，验证错误是否与文档一致 | required |
| 数据变化 | 操作后检查数据状态是否与文档描述一致 | required |
| 状态转换 | 操作后检查状态是否按文档描述转换 | required |
| 副作用 | 操作后检查是否产生了文档未提及的副作用 | suggestion |
| 幂等性 | 重复执行文档操作，验证结果是否如文档所述 | suggestion |
| 回滚结果 | 执行文档描述的回滚操作，验证是否恢复正常 | required |

**常见违规**：结果不符（"安装后服务自动启动"但实际未启动）、错误码不符、遗漏副作用、回滚不完整、幂等性不符。

## 5. 流程步骤一致性

**规则**：文档描述的操作流程（步骤数、步骤顺序、步骤间的依赖关系、前置条件）必须与产品实际操作流程一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 步骤数量 | 按文档步骤逐一执行，记录实际需要的步骤数 | required |
| 步骤顺序 | 验证步骤顺序是否可执行 | required |
| 前置条件 | 验证文档声明的前置条件是否充分 | required |
| 依赖关系 | 验证步骤间的依赖关系是否正确 | required |
| 可选步骤 | 验证标记为可选的步骤是否确实可选 | suggestion |
| 并行/串行 | 验证文档描述的执行顺序是否必须串行 | suggestion |
| 条件分支 | 验证文档描述的条件分支是否完整 | required |

**常见违规**：缺少步骤、顺序错误、缺少前置条件、分支不完整、可选标记错误。

---

## 6. 功能描述一致性

**规则**：文档描述的功能特性、支持范围、行为逻辑必须与产品实际实现一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 功能存在性 | 验证文档描述的功能是否实际存在 | required |
| 功能行为 | 验证功能的实际行为是否与描述一致 | required |
| 支持范围 | 验证文档声明的支持范围是否准确 | required |
| 限制条件 | 验证文档列出的限制条件是否完整 | required |
| 功能优先级 | 验证功能执行优先级是否与文档描述一致 | suggestion |
| 配置生效方式 | 验证配置修改后的生效方式 | required |
| 功能互斥 | 验证文档是否正确描述了功能互斥关系 | required |

**常见违规**：功能不存在（"支持蓝绿部署"但产品无此功能）、行为不一致、范围过宽、遗漏限制、生效方式错误。

---

## 7. 界面截图一致性

**规则**：文档中的界面截图必须与产品当前版本的实际界面一致（UI元素、布局、文案、图标）。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 截图与当前版本一致 | 在产品中重现截图场景，对比界面 | required |
| UI元素存在 | 验证截图中出现的按钮/菜单/输入框在产品中是否存在 | required |
| 文案一致 | 验证截图中界面文字与产品实际显示一致 | required |
| 布局一致 | 验证截图中界面布局与产品实际布局一致 | suggestion |
| 图标一致 | 验证截图中的图标与产品当前图标一致 | suggestion |
| 路径可达 | 验证截图中展示的页面/弹窗在产品中可正常访问 | required |
| 数据状态 | 验证截图中的数据状态标注是否合理 | suggestion |

**常见违规**：版本过旧（v1.0截图用于v2.0文档）、文案不匹配、页面不存在、布局变更、数据过时。

---

## 8. 版本与特性一致性

**规则**：文档中声明的版本号、版本支持范围、特性可用性必须与产品实际情况一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 版本号准确 | 执行 `--version` 或检查产品版本文件 | required |
| 特性版本标记 | 验证标注"v2.0+支持"的特性是否确实从该版本开始支持 | required |
| 废弃版本标记 | 验证标注"v3.0废弃"的特性是否确实在该版本废弃 | required |
| 兼容性声明 | 验证文档声明的兼容性范围是否准确 | required |
| 升级路径 | 验证文档描述的升级路径是否可行 | required |
| API版本 | 验证文档引用的API版本是否可用 | required |

**常见违规**：版本号过时（"适用于v2.0"但v3.0已发布）、特性版本标记错误、兼容性过宽、升级路径不可行。

---

## 9. 错误信息一致性

**规则**：文档中列出的错误码、错误信息、错误处理方式必须与产品实际返回的错误一致。

| 检查项 | 验证方式 | 严重性 |
|--------|----------|:------:|
| 错误码 | 触发错误场景，验证实际错误码 | required |
| 错误信息文本 | 触发错误场景，验证实际错误文本 | required |
| 错误触发条件 | 按文档描述的条件触发错误，验证是否如期触发 | required |
| 错误处理方式 | 验证文档描述的错误处理步骤是否有效 | required |
| 错误等级 | 验证文档描述的错误等级是否准确 | suggestion |

**常见违规**：错误码不一致、错误信息不一致、触发条件不一致、处理方式无效。
