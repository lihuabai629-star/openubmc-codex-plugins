# 中文错别字检查规则大全

本文件收录所有中文错别字检查维度的详细规则、示例和检测方法。SKILL.md 中仅保留触发条件和核心流程，规则详情请查阅本文件。

## 一、豁免区域

- [ ] 代码块和行内代码中的文字不受错别字检查约束
- [ ] URL、文件路径、命令行中的文字不受错别字检查约束
- [ ] frontmatter 中的文字不受错别字检查约束
- [ ] 英文单词/短语的拼写不由本技能检查
- [ ] 专有名词/品牌名/产品名的非标准用字不报错（如公司注册名含异体字）
- [ ] 引用他人原文的内容不报错（但须标注为引用）

## 二、同音字/近音字混淆检查

### 2.1 "的/地/得"用法

- [ ] 定语修饰名词用"的"（"详细的文档"）
- [ ] 状语修饰动词用"地"（"详细地说明"）
- [ ] 动词后的补语用"得"（"说明得很详细"）
- [ ] "的"字短语（名词性）用"的"

### 2.2 "做/作"用法

- [ ] "做"用于具体动作、制造、从事（"做测试""做修改"）
- [ ] "作"用于抽象、书面语色彩、固定搭配（"作废""作用""操作""作为"）
- [ ] "作出贡献/决定"（书面语）vs "做出成绩/努力"（具体成果）

### 2.3 "在/再"用法

- [ ] "在"表示存在、位置、正在（"在终端中""正在运行"）
- [ ] "再"表示重复、继续（"再次尝试""再运行一次"）

### 2.4 "安装/按装"

- [ ] "安装"为正确写法（"安装软件包"），不写"按装"
- [ ] "按照"不写"安照"

### 2.5 "登录/登陆"用法

- [ ] "登录"用于计算机系统（"登录系统""登录账号"）
- [ ] "登陆"用于从水域到达陆地（"台风登陆"）

### 2.6 "启用/起用"用法

- [ ] "启用"用于设备/系统/功能（"启用新功能"）
- [ ] "起用"用于重新任用人（"起用新人"）

### 2.7 "反映/反应"用法

- [ ] "反映"用于告知情况（"反映问题""用户反映"）
- [ ] "反应"用于物质变化或回应（"化学反应""不良反应"）

### 2.8 "权力/权利"用法

- [ ] "权力"指支配力量（"管理员权力"）
- [ ] "权利"指合法利益（"用户权利"）

### 2.9 其他高频同音字对照表

**规则分工说明**：本表仅列出需要**语法/语义判断**的同音字（两个形式均为合法中文词但意义不同）。纯拼音输入法替换导致的整词错误（如"佩置→配置""服物→服务"等）统一归入§6.2（拼音输入错误对照表），避免重复。

| 正确 | 常见错误 | 区分要点 |
|------|----------|----------|
| 必须 | 必需 | "必须"= 一定要（副词）；"必需"= 不可缺少的（形容词），如"必需品" |
| 连接 | 联接 | "连接"用于物理/网络连接；"联接"为旧词，现代写作统一用"连接" |
| 关联 | 关连 | "关联"为正确写法 |
| 账号 | 帐号 | 现代汉语规范用"账号"（财物相关） |
| 账户 | 帐户 | 现代汉语规范用"账户" |
| 默认 | 缺省 | "默认"为现代标准写法；"缺省"为港台旧译，大陆文档用"默认" |
| 部署 | 步署 | "部署"为正确写法；"步"（bù）与"部"（bù）同音混淆 |
| 部署 | 布署 | "部署"为正确写法；"布"（bù）与"部"（bù）同音混淆 |

**注意**："布署"同时出现在§6.2（拼音输入错误对照表），此处侧重语义区分；"步署"为纯同音混淆，仅在本表列出。

### 2.9.1 "必须/必需"专项检测规则

"必需"本身是合法的中文形容词（意为"不可缺少的"），须结合语法位置判断：

- [ ] 若 `必需` 后紧跟 `为/被/创建/同时/排/在/满足/能` 等动词，应为 `必须`
  - 错误："数据必需为真实数据" → "数据必须为真实数据"
- [ ] 若 `必需` 在条件句结构中（"若…则必需""当…时必需"），应为 `必须`
- [ ] 若 `必需` 修饰名词（"必需品""必需元素"）或单独作谓语（"XX是必需的"），为正确用法，不标记

## 五、简繁混用检查

### 5.1 规则

- [ ] 同一文档中简体/繁体须统一；大陆文档统一用简体
- [ ] 禁止同一句中简繁混用

### 5.2 常见简繁混用对照（完整对照表见 simplified-traditional.md）

| 简体 | 繁体 |
|------|------|
| 信息 | 資訊 |
| 网络 | 網路 |
| 软件 | 軟體 |
| 数据库 | 資料庫 |
| 服务器 | 伺服器 |

### 5.3 常见混用错误

- [ ] 简体文档出现繁体字（如"點擊""伺服器"） → 标记为 required
- [ ] 繁体文档出现简体字（如"软件""网络"） → 标记为 required

## 六、拼音输入法导致的整词替换错误

### 6.1 规则

拼音输入法常导致整词替换为同音/近音词，这类错误往往语义不通但不明显，须逐词排查。

**规则分工说明**：本节覆盖**纯拼音替换**导致的整词错误（错误形式在中文中不构成有效词或构成无意义组合）。需要语法/语义判断的同音字（如"必须/必需""的/地/得"）归入§2.x。

### 6.2 高频拼音输入错误对照表（完整对照表见 pinyin-errors.md）

以下为最高频条目摘要：

| 正确 | 常见输入错误 | 拼音 |
|------|-------------|------|
| 配置 | 配至 | pèi zhì |
| 设置 | 设至 / 没置 | shè zhì |
| 运行 | 远行 | yùn xíng |
| 参数 | 参敷 / 灿数 | cān shù |
| 训练 | 训炼 | xùn liàn |
| 功能 | 工能 | gōng néng |
| 操作 | 草作 | cāo zuò |
| 部署 | 布署 | bù shǔ |
| 安装 | 按装 | ān zhuāng |

完整列表（60+ 条目）请查阅 `references/pinyin-errors.md`。

### 6.3 语义不通检测法

- [ ] 逐句阅读，检查每个词在当前语境中是否语义通顺
- [ ] 特别关注技术术语——如果术语"看起来不太对"，极可能是输入法替换错误
- [ ] 关注对照表中的高频错误词
- [ ] 检测步骤：对词与上下文语义匹配 → 若不在常见词汇表中且读音相近则标记 → 检查连续重复字（参见§6.5）

### 6.4 词序颠倒检查

拼音输入法或手误常导致双字词顺序颠倒。

#### 6.4.1 规则

- [ ] 检查双字词/多字词中是否存在字序颠倒
- [ ] 将文档词与标准词表对照，颠倒后无效则标记

#### 6.4.2 高频词序颠倒对照表（完整对照表见 word-order-errors.md）

以下为最高频条目摘要：

| 正确 | 常见颠倒 | 说明 |
|------|----------|------|
| 配置 | 置配 | pèi zhì → zhì pèi |
| 部署 | 署部 | bù shǔ → shǔ bù |
| 系统 | 统系 | xì tǒng → tǒng xì |
| 安装 | 装安 | ān zhuāng → zhuāng ān |
| 服务 | 务服 | fú wù → wù fú |
| 容器 | 器容 | róng qì → qì róng |

完整列表（18+ 条目）请查阅 `references/word-order-errors.md`。

**交叉引用**：`存储|储存` 见§7.2（术语规范），此处不重复。

#### 6.4.3 检测方法

- [ ] 对双字词检查其颠倒形式是否在常见中文词汇表中，若不在则大概率是字序错误
- [ ] 结合§2.x 和§6.2 交叉验证
- [ ] 注意排除成语修辞性倒装（技术文档中通常不存在）

### 6.5 重复字/漏字检查

输入法连击或手误常导致某个字被重复输入，或者某个字被遗漏。

#### 6.5.1 规则

- [ ] 检查相邻相同汉字（重复字错误）
- [ ] 检查双字词是否缩写为单字（漏字错误）
- [ ] 关注高频重复/遗漏模式

#### 6.5.2 高频重复字对照表（完整对照表见 dup-missing-chars.md）

以下为最高频条目摘要：

| 正确 | 常见重复错误 | 说明 |
|------|-------------|------|
| 用户 | 用户户 | 重复"户"字 |
| 参数 | 参数数 | 重复"数"字 |
| 配置 | 配置配 | 重复"配"字 |
| 安装 | 安装装 | 重复"装"字 |
| 系统 | 系统统 | 重复"统"字 |

完整列表（12+ 条目）请查阅 `references/dup-missing-chars.md`。

#### 6.5.3 高频漏字对照表

| 正确 | 常见遗漏错误 | 说明 |
|------|-------------|------|
| 服务器 | 服务 | 遗漏"器"字（如"推理服务"应为"推理服务器"） |
| 处理器 | 处理 | 遗漏"器"字（如"AI处理"应为"AI处理器"） |
| 操作系统 | 操作系 | 遗漏"统"字 |
| 分布式 | 布式 | 遗漏"分"字 |

**交叉引用**：`昇腾|升腾` 见§7.2（技术术语标准写法），`Ascend|Ascemd` 见§7.3（英文术语拼写），此处不重复。

#### 6.5.4 检测方法

- [ ] 扫描全文，匹配相邻重复汉字（排除叠词"渐渐""慢慢"等正常用法）
- [ ] 将文档词与标准词表对照，缺字后为非有效词则标记
- [ ] 结合§6.2 交叉验证

## 七、技术术语误写检查

### 7.1 规则

- [ ] 技术术语须使用业界约定写法
- [ ] 中文技术术语须使用标准译法
- [ ] 英文技术术语在中文文档中须保持原始拼写
- [ ] 不自行"翻译"已有标准中文名的英文术语

| 昇腾 | 升腾 | Ascend |
| 操作系统 | 操做系统 | operating system |

### 7.3 英文术语在中文文档中的拼写

- [ ] 英文术语保持原始拼写，不做中文音译
  - 正确："使用 Kubernetes 部署应用"
  - 错误："使用库伯奈提斯部署应用"
  - 正确："通过 API 调用服务"
  - 错误："通过诶皮艾调用服务"

|----------|-------------|
| Atlas | Atlass |
| Ascend | Ascemd |
| Kubernetes | K8s / Kubernates |
| MindSpore | MindSpere |
| Qwen2.5 | Qwen25 |
| kubectl | kubetl |

完整列表（18+ 条目）请查阅 `references/english-term-errors.md`。

### 7.4 术语表述一致性检查

同一文档中，同一概念的术语表述须前后一致，避免混用。

#### 7.4.1 规则

- [ ] 同一概念在全文中须使用一致的术语表述
- [ ] 常见不一致模式：

| 概念 | 不一致表述A | 不一致表述B | 说明 |
|------|-----------|-----------|------|
| 推理服务器 | 推理服务器 | 推理服务 | 全文应统一使用一种表述 |
| 训练服务器 | 训练服务器 | 训练服务 | 同上 |
| GPU | GPU | 显卡 | 技术文档中统一用"GPU" |
| 内存 | 内存 | 内储 | 统一用"内存" |

#### 7.4.2 检测方法

- [ ] 提取核心术语（产品名、组件名、操作名），检查全文表述是否一致
- [ ] 若不一致，标记为 suggestion 级别，建议统一为最常用表述

## 八、常见数字与单位错误

- [ ] 技术文档中数字用阿拉伯数字（"1 个节点"不写"一 个节点"）
- [ ] 日期用"2025年5月6日"不写"2025年5月6号"
- [ ] 量词正确搭配："1 台服务器""1 个进程""1 条命令"
- [ ] 服务器/设备量词用"台"不用"机"："单台 A3"不写"单机 A3"

## 九、其他常见中文错误

### 9.1 "的"字冗余

- [ ] "的"字连用不得超过两个

### 9.2 敬语误用

- [ ] 技术文档中不使用敬语（"您""敬请"等）

### 9.3 口语化表达

- [ ] 技术文档中避免口语化表达（"拷""跑""搞"等）

### 9.4 "其"字误用

- [ ] "其"须有明确指代对象

### 9.5 内容重复检查

- [ ] 检查相邻句子/段落是否存在完全重复或高度相似的内容

## 十、Gotchas（已知陷阱）

- **"必需"是合法中文词**：不能简单匹配替换，须按§2.9.1 判断
- **"服务"本身是合法词**："推理服务" vs "推理服务器" 需上下文判断（§6.5.3）
- **"仓库"≠"仓储"**：语义不同，需据语境判断（§6.2）
- **"缺省"在港台文档正确**：大陆文档标记为 suggestion，港台文档不标记（§2.9）
- **"结点"在数据结构语境中正确**：与"节点"需语境区分
- **"升腾"→"昇腾"**：华为品牌标准用字为"昇"（§7.2）
- **词序 vs 同音分类**："执行事件→执行时间"是同音混淆，引用§6.2 非§6.4
- **prescan.py 的局限性**：脚本仅做字典级精确匹配，无法识别变体、上下文依赖的语义错误（如"的/地/得"的语法判断）。LLM 必须负责这部分检查
- **medium confidence 必须复核**：脚本输出的 medium 命中若不复核而直接报告，易产生大量 false positive（如"申明"在"申明立场"中是正确用法）
