# 同音字/近音字用法详解

本文件为 `doc-typo-tester` skill 的参考文件（Rule 2.1-2.8），包含详细的示例和正误对照。

## 的/地/得 用法

- 定语修饰名词用"的"
  - 正确："详细的说明文档"
  - 错误："详细地说明文档"
- 状语修饰动词用"地"
  - 正确："详细地说明操作步骤"
  - 错误："详细的说明操作步骤"
- 动词后的补语用"得"
  - 正确："说明得很详细"
  - 错误："说明的很详细"
- "的"字短语（名词性）用"的"
  - 正确："这是需要安装的"
  - 错误："这是需要安装地"

## 做/作 用法

- "做"用于具体动作、制造、从事
  - 正确："做测试""做修改""做实验"
  - 错误："作测试""作修改""作实验"
- "作"用于抽象、书面语色彩、固定搭配
  - 正确："作废""作用""操作""作业""作者""作为""作出决定"
  - 错误："做废""做用""操做""做业""做者""做为""做出决定"
- 常见固定搭配：
  - "作出贡献/决定/判断/回应"（书面语搭配用"作"）
  - "做出成绩/榜样/努力"（具体成果搭配用"做"）

## 在/再 用法

- "在"表示存在、位置、正在
  - 正确："在终端中执行""在配置文件中""正在运行"
  - 错误："再终端中执行""再配置文件中""正再运行"
- "再"表示重复、继续
  - 正确："再次尝试""重新安装""再运行一次"
  - 错误："在次尝试""在运行一次"

## 登录/登陆 用法

- "登录"用于计算机系统、网站、账号的进入操作
  - 正确："登录系统""登录账号""登录服务器"
  - 错误："登陆系统""登陆账号""登陆服务器"
- "登陆"用于从水域到达陆地
  - 正确："台风登陆""登陆作战"
  - 错误："台风登录"

## 启用/起用 用法

- "启用"用于开始使用设备、系统、功能
  - 正确："启用新功能""启用防火墙"
  - 错误："起用新功能""起用防火墙"
- "起用"用于重新任用人
  - 正确："起用新人""起用退休干部"

## 反映/反应 用法

- "反映"用于把客观情况告诉上级或他人
  - 正确："反映问题""用户反映""反映了系统缺陷"
  - 错误："反应问题""用户反应""反应了系统缺陷"
- "反应"用于物质变化或回应行为
  - 正确："化学反应""反应速度""不良反应"

## 权力/权利 用法

- "权力"指支配力量（政治、管理）
  - 正确："管理员权力""系统权限和权力"
- "权利"指合法利益（法律）
  - 正确："用户权利""知识产权"
