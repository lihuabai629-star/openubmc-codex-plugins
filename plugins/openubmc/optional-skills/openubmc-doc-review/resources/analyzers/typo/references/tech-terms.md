# 中文技术术语标准写法对照

本文件为 `doc-typo-tester` skill 的参考文件（Rule 7.2），覆盖技术术语的常见误写。

| 标准写法 | 常见误写 | 英文原文 |
|----------|----------|----------|
| 服务器 | 伺服器（繁体用法） | server |
| 数据库 | 资料库（港台用法） | database |
| 处理器 | 处置器 | processor（"处置器"为拼音输入错误，"处"chǔ + "理"lǐ 误输入为"处"chǔ + "置"zhì） |
| 昇腾 | 升腾 | Ascend（华为AI处理器品牌，"昇"为品牌标准用字，不可简写为"升"） |
| 操作系统 | 操做系统 | operating system |
| 开源 | 开原 | open source |
| 源代码 | 原代码 | source code |
| 内存 | 内寸 | memory |
| 带宽 | 带款 | bandwidth |
| 延迟 | 延持 | latency |
| 吞吐量 | 吞土量 | throughput |
| 防火墙 | 放火墙 | firewall（"防"与"放"同音混淆） |
| 负载均衡 | 负载均横 | load balancing |
| 容器编排 | 容器编骗 | container orchestration |
| 微服务 | 微服物 | microservice |
| 中间件 | 中间建 | middleware |
| 持续集成 | 持续几成 | continuous integration |
| 持续部署 | 持续部书 | continuous deployment |
| 版本控制 | 版板控制 | version control |
| 接口 | 街口 | interface / API |
| 协议 | 写议 | protocol |
| 加密 | 加蜜 | encryption |
| 解密 | 解蜜 | decryption |
| 算法 | 算发 | algorithm |
| 编译 | 边译 | compile |
| 调试 | 条试 | debug |
| 框架 | 框加 | framework |
| 插件 | 插健 | plugin |
| 令牌 | 领牌 | token |
| 路由器 | 路由气 | router |
| 交换机 | 交唤机 | switch |
| 域名 | 喻名 | domain name |
| 镜像 | 境像 | image |
| 实例 | 事例 | instance |
| 租户 | 祖户 | tenant |
| 实体 | 事实 | entity |
| 序列化 | 须列化 | serialization |
| 脱敏 | 脱密 | data masking（"敏"与"密"易混淆，数据脱敏≠脱密） |
| 灰度发布 | 灰都发布 | gray/canary release |
| 回调 | 汇调 | callback |
| 存储 | 储存 | storage（"存储"为计算机术语规范写法；"储存"为通用词，技术文档中统一用"存储"） |
| 流水线并行 | 流水并行 | pipeline parallelism（技术文档中应使用完整术语"流水线并行"） |
