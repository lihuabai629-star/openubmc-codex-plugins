# 重复字/漏字对照表

本文件为 `doc-typo-tester` skill 的参考文件（Rule 6.5）。

## 高频重复字对照表

| 正确 | 常见重复错误 | 说明 |
|------|-------------|------|
| 用户 | 用户户 | 重复"户"字 |
| 参数 | 参数数 | 重复"数"字 |
| 配置 | 配置配 | 重复"配"字 |
| 安装 | 安装装 | 重复"装"字 |
| 运行 | 运行行 | 重复"行"字 |
| 系统 | 系统统 | 重复"统"字 |
| 服务 | 服务务 | 重复"务"字 |
| 环境 | 环境境 | 重复"境"字 |
| 设置 | 设置置 | 重复"置"字 |
| 部署 | 部署署 | 重复"署"字 |
| 安装指南 | 安装装指南 | 重复"装"字 |
| 配置文件 | 配置配文件 | 重复"配"字 |

## 高频漏字对照表

| 正确 | 常见遗漏错误 | 说明 |
|------|-------------|------|
| 服务器 | 服务 | 遗漏"器"字（如"推理服务"应为"推理服务器"） |
| 处理器 | 处理 | 遗漏"器"字（如"AI处理"应为"AI处理器"） |
| 操作系统 | 操作系 | 遗漏"统"字 |
| 分布式 | 布式 | 遗漏"分"字 |
