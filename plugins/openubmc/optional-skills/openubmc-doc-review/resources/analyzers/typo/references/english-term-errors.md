# 英文术语拼写错误对照表

本文件为 `doc-typo-tester` skill 的参考文件（Rule 7.3）。

| 正确拼写 | 常见拼写错误 |
|----------|-------------|
| Atlas | Atlass |
| Ascend | Ascemd |
| Kubernetes | K8s（可接受的缩写，但首次出现应写全称） |
| Kubernetes | Kubernates / Kubenetes |
| repository | reposity / repositry |
| environment | enviroment（少一个n） |
| configuration | configration（少一个u） |
| authentication | authentification |
| authorization | authorisation（英式可接受，美式为 -ize） |
| certificate | certicate（少一个r） |
| encryption | encription |
| privilege | priviledge |
| separate | seperate |
| license | lisence |
| evaluation | evaluatin |
| kubectl | kubetl |
| MindSpore | MindSpere |
| Qwen2.5 | Qwen25 | 版本号中缺少小数点 |
