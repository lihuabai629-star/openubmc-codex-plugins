# 形近字混淆对照表

本文件为 `doc-typo-tester` skill 的参考文件（Rule 3.x）。

## 高频形近字对照表

| 正确 | 常见混淆 | 区分要点 |
|------|----------|----------|
| 己 | 已/巳 | "己"（jǐ）= 自己，开口；"已"（yǐ）= 已经，半闭；"巳"（sì）= 地支，全闭 |
| 戊 | 戌/戍/戎 | "戊"（wù）= 天干；"戌"（xū）= 地支；"戍"（shù）= 守卫；"戎"（róng）= 军事 |
| 日 | 曰 | "日"（rì）= 太阳/日子，窄长；"曰"（yuē）= 说，宽扁 |
| 人 | 入 | "人"= 人；"入"= 进入 |
| 大 | 太 | "大"= 大小；"太"= 过于 |
| 未 | 末 | "未"（wèi）= 没有，上横短；"末"（mò）= 末尾，上横长 |
| 天 | 夭 | "天"（tiān）= 天空，上横长；"夭"（yāo）= 夭折，上横短 |
| 千 | 干 | "千"（qiān）= 千万，撇起笔；"干"（gàn）= 干活，横起笔 |
| 土 | 士 | "土"（tǔ）= 土地，下横长；"士"（shì）= 人士，上横长 |
| 候 | 侯 | "候"= 等候/时候，有竖；"侯"= 诸侯，无竖 |
| 拔 | 拨 | "拔"（bá）= 拔出；"拨"（bō）= 拨动 |
| 折 | 拆 | "折"（zhé）= 折断；"拆"（chāi）= 拆开 |
| 暗 | 黯 | "暗"（àn）= 暗中；"黯"（àn）= 黯淡 |
| 融 | 溶 | "融"= 融合/消融；"溶"= 溶解（化学） |
| 即 | 既 | "即"（jí）= 就是/即将；"既"（jì）= 已经/既然 |
| 力 | 务 | "力"（lì）= 力量/能力；"务"（wù）= 事务/务必（如"服务器"不写"服力器"） |

## 技术文档中常见的形近字错误

| 正确 | 错误 | 语境 |
|------|------|------|
| 提示 | 提视 | 显示提示信息 |
| 点击 | 点系 | 鼠标操作 |
| 配置 | 配直 | 系统配置 |
| 运行 | 远行 | 程序运行 |
| 数据 | 数拒 | 数据库 |
| 网络 | 网终 | 网络连接 |
| 输入 | 输人 | 键盘输入 |
| 选项 | 逝项 | 选项设置 |
| 用户 | 月户 | 系统用户 |
| 服务 | 夫务 | 服务配置 |
| 文件 | 文什 | 文件管理 |
| 设备 | 没备 | 设备管理 |
| 服务器 | 服力器 | 服务器管理（"力"与"务"形近混淆） |
