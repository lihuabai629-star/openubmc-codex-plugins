# 易混词对照表

本文件为 `doc-typo-tester` skill 的参考文件（Rule 4.x），覆盖常见易混词和词语误用。

## 通用易混词

| 词语A | 词语B | A的用法 | B的用法 |
|-------|-------|---------|---------|
| 截止 | 截至 | "报名已经截止"（表示停止） | "截至2025年5月"（表示到某时） |
| 制定 | 制订 | "制定政策/方案"（确定下来，强调结果） | "制订计划/方案"（起草/创制，强调过程） |
| 爆发 | 暴发 | "爆发冲突/战争"（力量突然发作） | "暴发户/山洪暴发"（突然发财/突然发生） |
| 交代 | 交待 | "交代任务/问题"（嘱咐/说明） | "交待"为不规范写法，统一用"交代" |
| 沟通 | 勾通 | "沟通意见"（中性，交流） | "勾通敌人"（贬义，暗中勾结） |
| 淡薄 | 淡泊 | "意识淡薄"（不浓厚） | "淡泊名利"（不追求） |
| 品尝 | 品赏 | "品尝"为正确写法 | "品赏"为常见误写，正确写法为"品尝" |
| 突出 | 凸出 | "问题突出"（显著） | "表面凸出"（物理凸起） |
| 简洁 | 简捷 | "语言简洁"（简明扼要） | "方法简捷"（简单快捷） |
| 融化 | 溶化 | "冰雪融化"（物理变液） | "糖溶于水"（化学溶解）用"溶解" |
| 精致 | 精制 | "工艺精致"（精美） | "精制食品"（精细加工） |

## 技术文档高频易混词

| 词语A | 词语B | A的用法 | B的用法 |
|-------|-------|---------|---------|
| 适配 | 适合 | "适配多种平台"（使配合） | "适合新手"（符合条件） |
| 兼容 | 宽容 | "向下兼容"（软硬件配合） | "待人宽容"（心胸宽广） |
| 实例 | 事例 | "创建实例"（具体对象） | "举一个事例"（例子） |
| 实体 | 事实 | "数据库实体"（客观存在物） | "事实如此"（实际情况） |
| 释放 | 释怀 | "释放内存"（腾出资源） | "释怀心事"（心情解脱） |
| 回收 | 恢复 | "垃圾回收"（收回） | "恢复服务"（复原） |
| 依赖 | 依附 | "模块依赖"（需要） | "依附于政策"（附着） |
| 调用 | 调动 | "调用API"（程序使用） | "调动资源"（组织安排） |
| 覆写 | 复写 | "覆写方法"（override） | "复写纸"（carbon copy） |
| 声明 | 申明 | "声明变量"（declare） | "申明立场"（说明） |
| 异常 | 异状 | "抛出异常"（exception） | "出现异状"（不正常状态） |
