# 英文标点规则
## 2.1 冒号（英文）
- [ ] 冒号仅在完整句子后用于引出列表
  - 正确："The tool supports three languages: Python, Go, and Java."
  - 错误："The tool supports: Python, Go, and Java."
- [ ] 冒号后的文本不大写，除非是完整句子或专有名词开头
- [ ] 列表须由完整引导句引出，引导句以冒号结尾
- [ ] 标题不以冒号结尾
- [ ] 简短描述和摘要必须是完整句子，不能以冒号结尾的片段充当
- [ ] 可选步骤必须以 `Optional:` 开头（首字母大写、带冒号、不用括号）
  - 正确：`. Optional: Configure the activity types...`
  - 错误：`. (Optional) Configure...`（去掉括号，改用冒号）
  - 错误：`. (OPTIONAL) Configure...`（去掉括号，小写，改用冒号）
  - 错误：`. Optionally, configure...`（改用 "Optional:" 前缀）
  - 错误：`. Optionally configure...`（改用 "Optional:" 前缀）
- [ ] 条件步骤须明确说明条件，通常以 "if" 从句或上下文说明开头
  - 正确：`. If the storage_type is local, remove the extension files...`
  - 正确：`. Master repository only: In the IP address field, type the IP address.`
  - 正确：`. For restricted environments: Configure the proxy settings.`
  - 错误：`. If applicable, remove the extension files...`（太模糊）
- [ ] 冒号后 "following" 不能单独使用，须跟名词："the following items:" 而非 "the following:"
## 2.2 逗号（英文）
- [ ] 三个及以上项目的列表中，"and"/"or" 前须使用串行逗号（Oxford 逗号）
- [ ] 引导短语后使用逗号
- [ ] 限制性从句中 "that" 前不加逗号
- [ ] 非限制性从句中 "which" 前使用逗号
- [ ] 四位数及以上的数字使用逗号分隔：1,000 和 10,000
## 2.3 破折号（英文）
- [ ] 长破折号（Em dash —）用于强调或插入语，两侧不加空格
- [ ] 短破折号（En dash –）用于表示范围："pages 10–15"
- [ ] 连字符（Hyphen -）不可替代长破折号或短破折号
- [ ] 每句中最多一对长破折号
- [ ] 标题中使用长破折号（—），而非连字符（-）
## 2.4 省略号（英文）
- [ ] 省略号不用于语意未尽或暗示
- [ ] 省略号仅用于引用中的文字省略，或UI中表示"需要更多输入"
- [ ] 英文省略号使用三个点 "..."，不使用中文六点省略号
## 2.5 感叹号（英文）
- [ ] 技术文档中不使用感叹号
- [ ] 绝不使用多个感叹号（"!!!"）
- [ ] 正文中不使用感叹号（代码块除外）
## 2.6 连字符（英文）
- [ ] 复合形容词在名词前须加连字符："command-line interface"
- [ ] 复合形容词在名词后不加连字符："the interface is command line"
- [ ] 以 "-ly" 结尾的副词+形容词组合不加连字符："newly created file"
- [ ] 专有名词或数字前的前缀须加连字符："pre-2020"
- [ ] 常见前缀不加连字符：reuse, coexist, noncompliant, preinstall, multicloud
## 2.7 括号（英文）
- [ ] 括号应谨慎使用；重要内容应融入句子正文
- [ ] 括号不嵌套
- [ ] 标点符号放在括号外（除非整个句子都在括号内）
- [ ] 可选步骤标识不使用括号（改用 `Optional:`）
## 2.8 句号（英文）
- [ ] 句号后只留一个空格（不是两个）
- [ ] 列表中的完整句子以句号结尾
- [ ] 标题、副标题和按钮标签中不使用句号
- [ ] 列表项标点须一致：全部加句号或全部不加，不能混用
- [ ] 缩写词中不使用句号：US, UK, PhD, CEO
- [ ] 小数点使用句号：3.14
- [ ] 链接文本末尾不加句号
- [ ] 表格/图片标题末尾不加句号
- [ ] 时间格式中冒号分隔时与分：14:00 UTC
- [ ] **[SUGGESTION]** 句子不以数字开头（需拼写出来或改写句子结构；版本号、标题中的数字除外）
## 2.9 引号（英文）
- [ ] 双引号用于直接引用和标题
- [ ] 逗号和句号放在引号内（美式英语规范）
- [ ] 冒号和分号放在引号外
- [ ] 不用引号表示强调（应使用粗体或斜体）
- [ ] 代码术语使用等宽字体格式，而非引号
- [ ] UI元素不使用引号（应使用粗体）
- [ ] 引号嵌套时，外层使用双引号，内层使用单引号："She said, 'Hello.'"
## 2.10 分号（英文）
- [ ] 避免使用分号；应将句子拆分为独立句子
- [ ] 分号仅用于列表项本身包含逗号的复杂列表
## 2.11 斜线号（英文）
- [ ] 避免用斜线号表示"或"；应写出 "or"："Linux or macOS" 而非 "Linux/macOS"
- [ ] 不使用 "and/or"；应选择 "and"、"or" 或改写表述
- [ ] 已广泛使用的术语中可接受斜线号："client/server"、"TCP/IP"、"I/O"
## 2.12 单位规范（英文）
- [ ] 数字与单位之间加1个半角空格："100 MB"、"25°C"
- [ ] 百分比、度数符号直接跟随数字，无需空格："50%"、"180°"
- [ ] 单位统一使用半角格式，禁止使用全角单位
