# 常见错误（doc-punctuation-tester）

本文件列出中文文档、英文文档和中英混合文档中最常见的标点符号错误，供快速检查和培训参考。

## 7.1 英文文档常见错误

- [ ] 把所有内容写成疑问句或感叹句
- [ ] 过度使用句子片段追求效果
- [ ] 过度使用标点追求效果
- [ ] 列表内标点风格不一致（部分项有句号，部分没有）
- [ ] 操作步骤类列表项未统一加句号
- [ ] 用冒号引出本应是完整句子的片段
- [ ] 仅括号内内容被括起时，标点放在括号内

## 7.2 中文文档常见错误

- [ ] 中文句子中使用半角标点（. , : ; 等）
- [ ] 并列词语使用逗号而非顿号
- [ ] 软件产品名使用书名号《》
- [ ] 中文省略号写成三个点"..."而非六个点"……"
- [ ] 中文引号使用英文引号""而非中文引号" "" "
- [ ] 中文破折号只写一个"—"而非两个"——"
- [ ] "和/或"前多加顿号："Python、Go、和 Java"（"和"前不加顿号）
- [ ] 中文标点前后有多余空格
- [ ] 纯中文文字之间有多余空格
- [ ] 章节名使用书名号《》（章节名非独立文档，不用书名号）
- [ ] 中文句子中括号风格不一致（英文缩写括号应统一为全角或半角，不可混用）
- [ ] 操作步骤类列表项未统一加句号
- [ ] 代码块中混入中文全角标点（如 `。` `，` `；` `：` `（` `）`），导致代码无法运行
  - 示例（错误）：`print（hello）`——使用了全角括号，应改为 `print(hello)`
  - 示例（错误）：`result = a + b；`——使用了全角分号，应改为 `result = a + b;`
  - 示例（错误）：`print（"你好，世界"）`——全角括号和全角逗号，应改为 `print("你好，世界")`

## 7.3 中英混合文档常见错误

- [ ] 中文句子中混用英文半角标点
- [ ] 中英文之间空格风格不一致（部分加空格，部分不加）
- [ ] 英文术语周围使用了中文引号" "" "或书名号《》而非等宽字体
- [ ] 中文列表引导句使用半角冒号":"而非全角冒号"："
- [ ] 同一句中全角半角标点混用
- [ ] 链接到手册/指南的外链未使用书名号《》包裹 **[SUGGESTION]**
- [ ] 全角开括号与半角闭括号混搭："（世界)"
- [ ] 中文句子中括号内英文缩写使用半角括号时，左括号前缺少空格
- [ ] 括号风格策略不一致（部分按内容语言区分，部分统一全角）

## 7.4 错误示例对照

| 错误示例 | 正确示例 | 说明 |
|---------|---------|------|
| `请点击"保存"按钮` | `请点击「保存」按钮` 或 `请点击"保存"按钮` | 中文引号与英文引号不可混用 |
| `支持Python、Go、和Java` | `支持Python、Go和Java` | "和"前不加顿号 |
| `内存要求:4GB以上` | `内存要求：4 GB以上` | 冒号需全角，数字与单位间需空格 |
| `他说:"我完成了。"` | `他说："我完成了。"` | 中文句子需用全角冒号 |
| `openEuler24.03是最新版本` | `openEuler 24.03 是最新版本` | 中英文之间需空格 |
| `1.下载安装包2.解压文件` | `1. 下载安装包。 2. 解压文件。` | 有序列表项需加句号 |
| `**注意：**此操作不可逆` | `**注意**：此操作不可逆` 或 `**注意**：此操作不可逆` | 块标题末尾不应加冒号 |
| `print（"hello"）` | `print("hello")` | 代码块中必须使用半角括号 |
