# 中英混合文档规则
## 4.1 中英文之间的空格（规则ID：4.1，严重等级：suggestion）
⚠️ 处罚规则：同一文档中同时出现「中文+英文/数字加空格」和「中文+英文/数字不加空格」两种格式≥3处，**自动升级为required等级错误**，不得仍按suggestion统计
- [ ] 中文与英文/数字之间必须保持风格统一，全文一致：
  - 统一风格基准：以全文占比≥80%的格式为基准，剩余20%的不一致格式判定为违规
  - 统一风格1（推荐）：中文与英文/数字之间加空格，示例："使用 Python 3.12 进行开发"
  - 统一风格2（不推荐）：中文与英文/数字之间不加空格，示例："使用Python3.12进行开发"
  - **禁止两种风格混用**，混用即为违规
- [ ] 纯中文文字之间不加空格
  - 错误："你 好"（中文之间有空格）
  - 错误："文档 工具"（中文之间有空格）
  - 正确："使用 Vue 开发"（中英文之间有空格，不报错）
- [ ] 中文标点与英文/数字之间不加空格
  - 正确："支持Python、Go和Java。"
  - 错误："支持 Python、Go 和 Java 。"（标点前不应加空格）
## 4.2 标点随语言原则
- [ ] 中文句子中使用中文标点（全角），英文句子中使用英文标点（半角）
  - 正确："请在终端输入 `npm install`，然后重启服务。"（中文句子，中文逗号和句号）
  - 错误："请在终端输入 `npm install`, 然后重启服务."（中文句子，英文标点）
- [ ] 整句为英文时，使用英文标点
  - 正确："For more information, see the documentation."
  - 错误："For more information，see the documentation。"（英文句子，中文标点）
- [ ] 英文标点在中文上下文中的判定：英文标点前后均为英文字母/数字/标点/空格时，属于英文上下文，不报错
## 4.3 全角半角一致性
- [ ] 中文语境中不应混用全角和半角标点
  - 错误："请安装以下组件:Python、Go。"（半角冒号混在全角标点中）
  - 正确："请安装以下组件：Python、Go。"
- [ ] 英文语境中不应混用全角标点
  - 错误："Install the following components：Python, Go."（全角冒号混在英文标点中）
  - 正确："Install the following components: Python, Go."
## 4.4 引号匹配
- [ ] 中文语境使用中文引号""
  - 正确："点击"保存"按钮后，系统会提示确认。"
  - 错误："点击"保存"按钮后，系统会提示确认。"
- [ ] 英文语境使用英文引号""
  - 正确："Click the "Save" button to confirm."
  - 错误："Click the "Save" button to confirm."
## 4.5 括号匹配
- [ ] 中文语境使用全角括号（）
  - 正确："支持多种语言（包括 Python 和 Go）。"
  - 错误："支持多种语言(包括 Python 和 Go)。"
- [ ] 英文语境使用半角括号()
  - 正确："Supports multiple languages (including Python and Go)."
  - 错误："Supports multiple languages（including Python and Go）。"
- [ ] 中英混合文档中，括号的全角/半角根据括号**内容语言**决定（详见规则 3.10）：
  - 括号内容包含中文 → 全角括号（）
  - 括号内容为纯英文缩写/标注 → 可使用半角括号()，半角左括号前加空格
  - 同一文档内须统一策略
## 4.6 中英文列表标点
- [ ] 中英混合列表中，标点跟随列表项自身语言
  - 中文列表项以"。"结尾
  - 英文列表项以"."结尾
- [ ] 若所有列表项语言相同，则统一使用该语言的标点
