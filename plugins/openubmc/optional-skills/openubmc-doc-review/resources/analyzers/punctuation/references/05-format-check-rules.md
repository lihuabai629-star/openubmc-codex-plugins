# 标点符号格式检查
## 5.1 标点符号前后空格检查
- [ ] 中文标点符号前后不应有多余空格
  - 错误："你好 ，世界"（中文逗号前有多余空格）
  - 错误："你好， 世界"（中文逗号后有多余空格）
- [ ] 英文标点符号前不应有多余空格（前引号 `"` `'` 和左括号 `(` 除外）
  - 错误："hello , world"（英文逗号前有多余空格）
- [ ] 英文标点符号后不应有连续两个及以上空格
  - 错误："hello,  world"（英文逗号后有多余空格）
- [ ] 行尾不应有多余空格
## 5.2 连续标点符号检查
- [ ] 不应出现不合理的连续标点符号组合
  - 错误："你好，，世界"（连续两个中文逗号）
  - 错误："测试。。测试"（连续两个中文句号）

## 5.3 标点符号配对检查
- [ ] 成对标点符号必须正确配对和闭合
  - 错误："你好（世界"（缺少闭括号）
  - 错误："你好）世界"（缺少开括号）
  - 错误："你好【世界）"（开闭符号不匹配）
- [ ] 使用栈算法检查：开符号入栈，闭符号匹配栈顶，遍历结束后栈须为空
- [ ] 开闭符号必须属于同一配对表（见1.4 成对标点符号映射）
  - 错误："（世界]"（全角开括号与半角闭括号不匹配）
  - 错误："（世界)"（全角开括号与半角闭括号不匹配）
