# 中文标点规则
## 3.1 句号（中文）
- [ ] 中文句子使用全角句号"。"，不使用半角句号"."
  - 正确："请先安装依赖包。"
  - 错误："请先安装依赖包."
- [ ] 中文标题末尾不加句号
- [ ] 中文句子以英文缩写结尾时，仍使用中文句号"。"而非半角"."
  - 正确："该项目已发布到 GitHub。"
  - 错误："该项目已发布到 GitHub."
## 3.2 逗号（中文）
- [ ] 中文句子使用全角逗号"，"，不使用半角逗号","
  - 正确："安装完成后，请重启服务。"
  - 错误："安装完成后,请重启服务。"
- [ ] 中文句子中并列分句之间使用逗号
- [ ] 引导短语后使用全角逗号
## 3.3 顿号（中文特有）
- [ ] 并列场景规则：
  - 纯中文并列：使用顿号"、"分隔
  - 中英文混合并列：使用顿号"、"分隔
  - 纯英文/数字/代码并列：使用半角逗号","分隔
  - 正确："系统支持 Python、Go 和 Java。"（中英文混合并列）
  - 正确："支持的版本: 1.0, 2.0, 3.0"（纯数字并列）
  - 错误："系统支持 Python、Go、和 Java。"（"和"前不加顿号）
- [ ] 并列词语之间不使用逗号代替顿号
  - 正确："支持增、删、改、查操作。"
  - 错误："支持增，删，改，查操作。"
- [ ] 顿号与逗号区分：并列词语用顿号，分句用逗号
- [ ] 最后两个并列项之间用"和""或"连接，不用顿号
  - 正确："支持 Linux、macOS 和 Windows。"
  - 错误："支持 Linux、macOS、Windows。"
## 3.4 冒号（中文）
- [ ] 中文句子使用全角冒号"："，不使用半角冒号":"
  - 正确："请注意：此操作不可逆。"
  - 错误："请注意:此操作不可逆。"
- [ ] 中文列表引导句以全角冒号"："结尾
  - 正确："支持以下语言：" 然后跟列表
  - 错误："支持以下语言:" 然后跟列表
- [ ] 中文标题不以冒号结尾
- [ ] 中文可选步骤使用"可选："而非"Optional:"
  - 正确："可选：配置通知方式"
  - 错误："(可选) 配置通知方式"
  - 错误："Optional: 配置通知方式"
## 3.5 分号（中文）
- [ ] 中文使用全角分号"；"，不使用半角分号";"
- [ ] 中文复句中并列分句之间可使用分号
- [ ] 中文分号使用频率高于英文，但也不宜过多
## 3.6 省略号（中文）
- [ ] 中文省略号使用两个省略号字符"……"（两个 U+2026 HORIZONTAL ELLIPSIS），占两个汉字宽度，不使用三个 ASCII 句号"..."、六个 ASCII 句号"......"或英文省略号
  - 正确："请输入更多参数……"（两个 U+2026）
  - 错误："请输入更多参数..."（三个 ASCII 句号，属于英文风格）
  - 错误："请输入更多参数......"（六个 ASCII 句号，非标准中文省略号）
  - 错误："请输入更多参数。。。。。。"（全角句号，非省略号）
- [ ] 中文省略号不用于语意未尽或暗示
- [ ] 单一省略号字符"…"（一个 U+2026）可用于UI标签等空间受限场景，但正文中应使用"……"
## 3.7 破折号（中文）
- [ ] 中文破折号占两个汉字宽度"——"，不同于英文 em dash "—"
  - 正确："这款产品——业界领先的解决方案——已全面升级。"
  - 错误："这款产品—业界领先的解决方案—已全面升级。"（宽度不够）
- [ ] 中文数值范围使用"～"或"—"，不使用英文 en dash "–"
  - 正确："页码 1～10"
  - 正确："2020—2025 年"
  - 错误："pages 1–10"（中文语境中不应使用英文 en dash）
- [ ] **章节引用分隔符**：引用其他章节/小节名时，分隔符可使用连字符" - "（两侧加空格），而非中文破折号"——"
  - 正确："请参阅 新功能和增强 - 安装程序和镜像创建。"
  - 正确："请参阅 新功能 - 安全性。"
  - 此规则仅适用于章节引用中的分隔符，正文插入语仍须使用中文破折号"——"
## 3.8 引号（中文，严重等级：Required）
- [ ] 中文语境下**禁止使用英文半角引号""和''**，无论是否统一均为Required错误
  - 中文引号仅需全文统一类型即可：可选择全角弯引号「"〞」或直角引号「「」」，不强制具体类型，保持一致即可
  - 正确："请点击"保存"按钮。"（弯引号）
  - 正确："请点击「保存」按钮。"（直角引号）
  - 错误："请点击"保存"按钮。"（英文引号，Required错误）
- [ ] 引号嵌套时，外层使用双引号，内层使用单引号
  - 正确："他说：'这个方案可行。'"
- [ ] 不用引号表示强调（应使用粗体）
- [ ] 代码术语使用等宽字体格式，而非中文引号
- [ ] 新术语首次出现时可使用引号标示，后续不再使用
## 3.9 书名号（中文特有，默认Required，标注[SUGGESTION]除外）
- [ ] 仅**独立可访问的文档、手册、标准、法律法规、正式出版物名称**使用书名号《》，其余场景禁止使用：
  - 正确："请参阅《openEuler 24.03 安装指南》获取详细信息。"（独立手册，有独立URL）
  - 正确："《中华人民共和国网络安全法》"（法律法规）
  - 错误："请参阅"安装指南"获取详细信息。"（独立文档未用书名号）
- [ ] 文章/博客标题可使用书名号《》或引号""，但全文必须统一
- [ ] 章节/小节名、文档内部标题**禁止使用书名号《》**，直接引用即可
  - 正确："请参阅 2.3 安装程序和镜像创建 章节。"
  - 错误："请参阅《2.3 安装程序和镜像创建》。"（章节名非独立文档，Required错误）
  - **判定标准**：独立文档=可单独发布、有独立URL、可单独下载访问；章节名=文档内部的局部标题，无法单独访问
- [ ] 文件名、配置项名、代码术语、软件产品名**禁止使用书名号**
  - 正确："使用 `config.yaml` 配置文件。"
  - 正确："使用 Kubernetes 部署应用。"
  - 错误："使用《config.yaml》配置文件。"（Required错误）
  - 错误："使用《Kubernetes》部署应用。"（Required错误）
- [ ] **[SUGGESTION]** 链接到"手册"或"指南"的外链建议使用书名号《》包裹，但非强制
  - 推荐写法：`[《安装指南》](url)`
  - 可接受写法：`[安装指南](url)`
  - 推荐写法：`<a href="url">《快速入门指南》</a>`
### v3.1量化触发条件（任一满足即触发，否则不报，消除模型主观判断）
| 触发条件 | 是否触发Suggestion | 示例 |
|----------|--------------------|------|
| 链接文本中含明确出版物词汇（"指南"、"手册"、"白皮书"、"规范"、"标准"、"教程"、"参考"） | **必报** | `[安装指南](url)` → 报 |
| 链接目标为外部完整网站根目录或文档首页 | **必报** | `[官方文档](https://docs.example.com/)` → 报 |
| 链接文本为专名（"安装指南"、"管理员指南"、"用户手册"、"开发者指南"等） | **必报** | `[管理员指南](url)` → 报 |
| 链接文本仅为通用词（"列表"、"页面"、"文档"、"链接"、"这里"、"详情"） | **不报** | `[兼容性列表](url)` → 不报 |
| 链接为同站内 `.md` 文件且文件名为通用词（如`overview.md`、`intro.md`） | **不报** | `[概述](overview.md)` → 不报 |
| 链接指向同文档锚点（`#section`） | **不报** | 锚点链接非独立文档 |
## 3.10 括号（中文）
- [ ] 中文句子中，括号的全角/半角根据括号**内容语言**决定：
  - 括号内容包含中文时，使用全角括号（）
    - 正确："请填写用户名（必填）。"
    - 正确："支持多种语言（包括 Python 和 Go）。"
    - 错误："请填写用户名(必填)。"
  - 括号内容为纯英文缩写/首字母缩略词/英文标注时，可使用半角括号()，且半角左括号前加空格
    - 正确："远程桌面协议 (RDP) 取代了 VNC。"
    - 正确："post-quantum 加密 (PQC) 算法。"
    - 正确：".NET 10.0 (Long-Term Support)。"
    - 错误："远程桌面协议(RDP)取代了 VNC。"（半角左括号前缺少空格）
  - **同一文档内括号风格须一致**：选择"按内容语言区分"或"统一全角"，不可混用
- [ ] 括号应谨慎使用；重要内容应融入句子正文
- [ ] 括号不嵌套
- [ ] 中文句子中括号外的标点放在括号外
## 3.11 间隔号（中文特有）
- [ ] 外国人名各部分之间使用间隔号"·"
  - 正确："John·Smith"
  - 错误："John Smith"（当作为中文语境中的外文名时）
- [ ] 书名与篇名之间使用间隔号
  - 正确："《论语·学而》"
## 3.12 感叹号（中文）
- [ ] 中文技术文档中不使用感叹号
- [ ] 绝不使用多个感叹号（"！！！"）
- [ ] 中文正文中不使用感叹号（代码块除外）
## 3.13 单位规范（中文）
- [ ] 数字与单位之间加1个半角空格："100 MB"、"25°C"
- [ ] 百分比、度数符号直接跟随数字，无需空格："50%"、"180°"
- [ ] 单位统一使用半角格式，禁止使用全角单位
